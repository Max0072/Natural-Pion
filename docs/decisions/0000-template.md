# ADR NNNN -- the decision, as a short sentence

- **Status:** Proposed | Accepted | Superseded by ADR NNNN | Withdrawn
- **Date:** YYYY-MM-DD
- **Decided by:** the user | project (measurement) | ...

## Context

What forced a decision: the situation, the numbers, what had been believed.

## Decision

What is now done, in the present tense and unambiguously. If it replaces an
earlier decision, say which.

## Consequences

What this changes, what it costs, what it rules out, and what remains open.

## Evidence

The measurement or the source: run directories, job ids, journal entries, file
paths. A decision without evidence beside it will be reopened by the next reader.
