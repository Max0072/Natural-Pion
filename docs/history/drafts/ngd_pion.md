# NGD-Pion — алгоритм прекондиционирования в чистом виде

Здесь зафиксирована версия алгоритма с полным учетом статистики backward-ошибок (`S`), раздельными EMA-коэффициентами и отказом от хрупкого trust-region в пользу честного преконционирования.

---

## 0. Геометрия

Pion обновляет `W ∈ R^{d_out×d_in}` двусторонним поворотом
`W ← R_out · W · R_in`, обе `R` ортогональны. Сингулярные числа `W`
не меняются никогда — двигаются только сингулярные векторы. Обучаемое
содержимое живёт в алгебре Ли `so(d)`, то есть в кососимметричных матрицах.

Следствие: спектр инициализации = спектр финальной модели, навсегда.

---

## 1. Генераторы

```
G_in  = Wᵀ G − Gᵀ W          (d_in × d_in,  кососимметричная)
G_out = G Wᵀ − W Gᵀ          (d_out × d_out, кососимметричная)
```

Это в точности удвоенный риманов градиент по повороту:

```
⟨G, W·X_in⟩ = ½⟨G_in, X_in⟩       для любой кососимметричной X_in
⟨G, X_out·W⟩ = ½⟨G_out, X_out⟩
```

Для одного сэмпла `G = δxᵀ` генератор — бивектор `G_in = δ' ∧ x`,
где `δ' = Wᵀδ`. Ранг 2. Батч из `B` токенов даёт ранг ≤ `2B`.

---

## 2. Оператор Фишера (Прекондиционер)

Оператор Фишера строится на обеих статистиках для каждой стороны:

```
F_in(X)  = 2 (A X S' + S' X A)      где S' = Wᵀ S W
F_out(X) = 2 (S X A' + A' X S)      где A' = W A Wᵀ
```

где:
- `A = E[xxᵀ]` — статистика активаций (in-сторона)
- `S = E[δδᵀ]` — статистика ошибок (out-сторона)

Операторы самосопряжены и PSD на кососимметричном подпространстве.

---

## 3. Статистики и EMA (каждый шаг)

Статистика градиентов/ошибок (`S`) меняется быстрее активаций (`A`), поэтому коэффициент сглаживания EMA для нее меньше:

```
A ← β_A A + (1−β_A) xxᵀ / n            β_A = 0.95
S ← β_S S + (1−β_S) δδᵀ / n            β_S < β_A  (например, 0.90)
```

Точность накопления: **fp32 минимум** (bf16 дает критическую ошибку).

---

## 4. Факторизация пучков (раз в T_fac шагов)

Конгруэнция пучков через симметричный корень для обеих сторон (`S ≠ I`):

**in-сторона** — пучок `(A, S')`:
```
A = U Σ Uᵀ                              (eigh)
Σ ← Σ + ε_A · λ_max(A)                  ε_A ОТНОСИТЕЛЬНЫЙ
A^{-1/2} = U Σ^{-1/2} Uᵀ
M_in  = A^{-1/2} S' A^{-1/2}
M_in  = Q_in Λ_in Q_inᵀ                 (eigh)
P_in  = A^{-1/2} Q_in
```

**out-сторона** — пучок `(S, A')`:
```
S = V Σ_S Vᵀ                            (eigh)
Σ_S ← Σ_S + ε_S · λ_max(S)              ε_S ОТНОСИТЕЛЬНЫЙ
S^{-1/2} = V Σ_S^{-1/2} Vᵀ
M_out = S^{-1/2} A' S^{-1/2}
M_out = Q_out Λ_out Q_outᵀ              (eigh)
P_out = S^{-1/2} Q_out
```

---

## 5. Применение прекондиционера (каждый шаг)

Вычисление естественного направления обновления через обращение оператора Фишера (в фактор-базисе):

```
Ỹ = Pᵀ G_skew P
Y_ij = Ỹ_ij / (2(Λ_i + Λ_j) + ε_F)      если 2(Λ_i+Λ_j) > rtol·max
Y_ij = 0                                иначе   ← МАСКА (нулевые моды)
X    = skew(P Y Pᵀ)
```

Маска обязательна для отсечения вырожденных и нулевых модных зон (особенно при неквадратной `W`).

---

## 6. Почему убран Trust-Region

На больших масштабах факторизация пучков (k-fac-like аппроксимация) неизбежно накапливает ошибку из-за неполной факторизуемости реальных распределений. В результате:
- Оценка кривизны по модели начинает расходиться с реальностью.
- Динамический коэффициент `α_t` начинает искусственно и хаотично «душить» шаг не из-за реального изменения геометрии, а из-за аппроксимационного шума.

**Позиционирование:** Алгоритм работает как **структурный прекондиционер** риманова градиента. Он выравнивает обусловленность задачи и масштабирует направления с учетом геометрии данных, а итоговая длина шага отдается под контроль стандартного оптимизатора (например, со своими расписаниями learning rate).

---

## 7. Обновление весов

```
W ← Cayley(−η X_out) · W · Cayley(−η X_in)

Cayley(−cX) = (I + c/2 · X)⁻¹ (I − c/2 · X)
```

Где `X_in`, `X_out` — прекондиционированные кососимметричные градиенты, а `η` задается внешним оптимизатором. Cayley гарантирует строгую ортогональность ретракции при любом вещественном шаге.

---

## Решения и почему

| решение | почему |
|---|---|
| Отказ от $S = I$ | Изотропный $S$ не показал стабильности на практике; возвращен честный учет $S = \mathbb{E}[\delta\delta^\top]$ для обеих сторон. |
| Раздельные $\beta_A$ и $\beta_S$ | Статистика градиентов/ошибок ($S$) меняется быстрее активаций ($A$), поэтому $\beta_S < \beta_A$ (например, 0.90 против 0.95). |
| Конгруэнция пучков на обеих сторонах | Из-за $S \neq I$ обе стороны требуют честной конгруэнции через симметричный корень $A^{-1/2}S'A^{-1/2}$ и $S^{-1/2}A'S^{-1/2}$. |
| Отказ от Trust-Region | K-FAC аппроксимация факторизации накопительно теряет точность на больших масштабах. Оценка кривизны начинает врать, и trust-region необоснованно душит шаг. |
| Позиционирование как прекондиционер | Направление выравнивается римановым Фишером, а масштабирование шага отдается внешнему оптимизатору / LR schedule. |
| Маска мёртвого блока | Сохранена: спасает от $0/0$ и деления float-шума на нули (особенно для неквадратных $W$). |
| fp32 для накопления | Обязательно: bf16 дает критическую ошибку накопления статистик в $10^3\dots10^4$ раз. |

## Открытые вопросы

1. **Квадратные vs неквадратные слои.** При $d_{in} > d_{out}$ часть энергии шага уходит на вращение игнорируемых входных направлений в рабочее подпространство. Нужно проверить необходимость адаптивной фильтрации / проекции.
2. **Momentum на прекондиционированном градиенте.** Фишер выравнивает геометрию, но не снижает дисперсию батча. Добавление momentum к $X_{in}, X_{out}$ перед ретракцией Cayley — главный кандидат на повышение стабильности на шумных данных.
3. **Частота факторизации ($T_{fac}$).** Так как trust-region убран, подбор $T_{fac}$ теперь основывается на отслеживании дрейфа подпространств (например, через cosine similarity свежего и старого $P$).
